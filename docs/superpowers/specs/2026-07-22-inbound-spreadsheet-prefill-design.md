# 自助入库表格导入预填设计

## 目标

在自助入库页面右上角增加“下载模板”和“导入表格”按钮。用户可选择 Excel 或 CSV 工装清单，解析成功并确认覆盖后，将数据填入下方可编辑表格；只有点击“确认入库”才写入数据库。

## 范围

- 支持 `.xlsx`、`.xls`、`.csv` 文件。
- 下载专用于自助入库的六列表格模板，默认保存到 Windows 桌面。
- 只读取第一个工作表。
- 支持列名：`资产编号/工装ID`、`名称/工装名称`、`型号/规格型号`、`序列号`、`工作中心`、`库位`。
- 忽略完全空白行和不属于上述字段的额外列。
- 导入成功后弹窗显示有效行数；确认后整体覆盖当前清单，取消后不改变当前清单。
- 导入只预填，不修改入库人、不查询或写入业务数据库。
- 缺少必填值的行仍预填，用户可直接在表格中补充；最终提交继续使用现有整批校验。

## 不在范围内

- 不改变管理员“导入 Excel 数据”的直接入库行为。
- 不增加追加、合并、去重或自动修正资产编号功能。
- 不读取多个工作表。
- 不修改数据库结构和入库事务。

## 页面交互

```text
┌──────────────────────────────────────────────────────┐
│ [返回首页]       自助入库       [下载模板] [导入表格] │
├──────────────────────────────────────────────────────┤
│ 入库人：[请选择]                                     │
│                                                      │
│ 工装清单（可批量）                       [新增一行]   │
│ ┌──────────────────────────────────────────────────┐ │
│ │ 资产编号｜名称｜型号｜序列号｜工作中心｜库位      │ │
│ └──────────────────────────────────────────────────┘ │
│                         [确认入库]                   │
└──────────────────────────────────────────────────────┘
```

导入流程：

1. 点击“导入表格”，打开系统文件选择窗口。
2. 选择文件后在 Electron 主进程读取并解析文件，但不访问数据库。
3. 文件无法读取、没有有效数据或没有可识别列时，显示中文错误，当前清单保持不变。
4. 解析成功后弹窗：“检测到 N 条工装，将覆盖当前清单，是否继续？”
5. 确认后替换下方清单并提示“已导入 N 条，请核对后确认入库”；取消后保留原清单。

## 组件与数据流

- `electron/services/excel.service.ts`：新增自助入库模板生成和纯文件解析函数。解析结果统一转换为 `InboundToolItem[]`。
- `electron/ipc/importExport.ipc.ts`：新增支持 Excel/CSV 的文件选择及“解析自助入库文件”处理器。
- `electron/preload.ts`、`src/api/systemApi.ts`：暴露类型安全的模板下载和预填导入方法。
- `src/views/Inbound.vue`：增加按钮、加载状态、覆盖确认和清单替换。
- `src/types/inbound.ts`：复用 `InboundToolItem`，不新增数据库模型。

## 错误与安全边界

- 只有解析成功且用户确认后才替换内存中的 `items`。
- 文件选择取消、解析失败、确认取消均不改变当前表单。
- 字段统一转换为去除首尾空格的字符串，避免数字、空值和 CSV 类型差异泄漏到 Vue 表格。
- 资产编号和序列号按显示值读取，尽量保留 Excel 单元格格式中的前导零。
- 真正入库仍由现有 `batchInbound` 做重复编号、已存在编号和必填字段校验，并保持整批事务回滚。

## 验收标准

- 页面右上角同时显示“下载模板”和“导入表格”。
- 模板包含资产编号、名称、型号、序列号、工作中心、库位六列。
- Excel、XLS、CSV 的有效数据可以预填到下方表格。
- 导入前弹出覆盖确认；取消或解析失败时原清单不变。
- 导入动作本身不产生工装台账或入库记录。
- 用户可编辑导入数据并通过原“确认入库”流程提交。

## 回滚

本变更不迁移数据。删除新增的 IPC/API/解析函数和页面按钮即可回到旧行为，无需清理数据库。
